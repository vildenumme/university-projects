This repository contains my penetration testing report created as part of the Ethical Hacking course in my Bachelor's degree in Cybersecurity at Kristiania.
The project was a two-week assignment where the goal was to perform a penetration test against an intentionally vulnerable environment.

Result: Passed ✅

---

## 🎯 Project Overview

The purpose of the assignment was to apply penetration testing methodology in practice.
The environment consisted of intentionally vulnerable systems and web applications used for educational purposes.

The testing included areas such as:

* Network and service enumeration
* Web application reconnaissance
* Vulnerability scanning
* Manual vulnerability testing
* Authentication and access control
* Injection vulnerabilities
* Security misconfigurations
* TLS and HTTP security
* Risk assessment
* Remediation recommendations

---

## 🛠️ Tools

Some of the tools used during the assessment:

`Nmap` · `Nikto` · `OWASP ZAP` · `Nessus` · `Burp Suite` · `SQLmap` · `John the Ripper` · `Kali Linux`

Testing combined automated scanning with manual verification to reduce false positives and better understand the vulnerabilities identified.
